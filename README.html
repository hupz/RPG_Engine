Быстрый старт

После распаковки ZIP у вас есть готовый набор файлов. Ничего устанавливать не нужно — достаточно браузера (Chrome, Edge, Firefox).

  1. Откройте editor.html двойным щелчком или через «Открыть файл» в браузере.
  2. Нажмите 📂 Загрузить JSON и выберите data/game_data.json — или создайте проект кнопкой 📄 Новый проект.
  3. Редактируйте сцены во вкладке 🎬 Сцены, сохраняйте проект кнопкой 💾 Сохранить JSON.
  4. Откройте index.html, выберите кампанию и нажмите ▶ Играть — проверьте сюжет в действии.

Создание первой сцены

Сцена — это экран с текстом, диалогами, кнопками выбора и опционально боем.

  1. В сайдбаре слева нажмите + Новая сцена или выберите шаблон.
  2. Заполните ID сцены латиницей без пробелов (например village_square) — по этому ID ссылаются переходы.
  3. Укажите Локацию (название для игрока) и Текст сцены.
  4. В блоке 🔀 Выборы добавьте кнопку: текст, иконка, тип «Переход», целевая сцена в поле Сцена (переход).
  5. Сохраните JSON и проверьте проект кнопкой 🔍 Проверить проект — исправьте битые ссылки, если есть.

Добавление NPC

NPC (неигровые персонажи) хранятся во вкладке 👥 NPC и могут привязываться к сценам для репутации и диалогов.

  1. Откройте вкладку 👥 NPC → выберите NPC в списке или создайте нового.
  2. Укажите ID, Имя (обязательно), Иконку и описание.
  3. На сцене в поле NPC сцены выберите персонажа — при первом визите сработают эффекты репутации «при разговоре».
  4. Диалоги можно добавить в блоке 🗣️ Диалоги на сцене или через компоненты дерева диалогов (см. полное руководство).

Тестирование

Проверяйте игру на каждом этапе — так вы не сломаете сюжет случайной опечаткой в ID сцены.

В редакторе

  • 🔍 Проверить проект — линтер: битые переходы, тупики, NPC без имени, квесты без награды.
  • Панель «Ошибки» внизу — список проблем; клик по строке открывает проблемное место.
  • ▶ Play в превью сцены — быстрый просмотр текста и кнопок без полного запуска игры.
  • ↩ / ↪ — отмена и повтор последних правок в текущей сцене или объекте.

В игре (index.html)

  • Выберите кампанию, создайте персонажа, пройдите ключевые ветки.
  • Сохранение — автоматически при смене сцены; вручную — через меню 📁 в боковой панели.
  • Кнопка 🏆 Достижения показывает прогресс трофеев (если настроены в редакторе).

Экспорт игры

Чтобы отдать игру игрокам без редактора, соберите standalone-пакет.

  1. В редакторе загрузите и сохраните актуальный game_data.json.
  2. Нажмите 📦 Экспорт игры в шапке редактора.
  3. Укажите пустую папку — движок скопирует index.html, css/, js/ и сгенерирует js/data.js из вашего JSON.
  4. Раздайте эту папку целиком. Игрок открывает index.html — редактор в пакет не входит.
Важно: для работы с локального диска (file://) экспорт встраивает данные в data.js. Если размещаете игру на веб-сервере, можно также положить JSON в data/.

Советы

  • Используйте ❓ Подсказки рядом с полями редактора — не нужно каждый раз листать гайд на 200+ страниц.
  • Держите ID сцен короткими и понятными: mill_door, а не scene_47_final_v2.
  • После боя всегда указывайте Сцену после победы — иначе игра зависнет на чёрном экране.
  • Квесты ведите через вкладку 📜 Квесты и стадии — не плодите лишние флаги вручную.
  • Включите тёмную тему (☀/🌙 в шапке), если работаете вечером.
  • Регулярно жмите 💾 Сохранить JSON — браузер не заменяет файловый бэкап на диске.

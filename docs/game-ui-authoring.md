# Game UI Designer (без кода)

## Зачем

**Visual Scene** — картинка локации и hotspot.  
**Game UI** — меню и HUD поверх нескольких сцен.

## Как открыть

Command Palette / команда **Игровой интерфейс (Game UI)**  
или `Editor.openGameUiEditor()` в консоли редактора.

## Пресеты

| Пресет | Что создаёт |
|--------|-------------|
| `main_menu` | фон + заголовок + кнопки сохранить/загрузить |
| `basic_hud` | портрет, имя, уровень, HP, золото, кнопки инвентарь/журнал |
| `character_status` | компактный блок персонажа |
| `bottom_action_bar` | нижняя панель действий |

После пресета **каждый узел можно** двигать, удалять, менять текст и On Click.

## Элементы

Изображение, Текст, Кнопка, Панель, Полоска HP, Золото, Уровень, Портрет.

## On Click (готовые действия)

- Открыть журнал → `open_panel` / journal  
- Открыть инвентарь → `open_panel` / inventory  
- Сохранить / Загрузить  
- Открыть сцену → `change_scene`

## Данные игрока

В тексте: `{gold}`, `{level}`, `{hp}`, `{maxHp}`, `{name}`.

## Постоянный / для сцены

- **Постоянный HUD** — остаётся при Village → Tavern.  
- **Только для сцены** — укажите ID сцены; при уходе слой снимается.

## Runtime

`UIRuntime` монтируется из `SceneManager.showScene`.  
Editor **не** нужен в production.

## Создание HUD с нуля (1.9.1)

1. Сайдбар → **Игровой UI**.
2. **+ Экран** или пресет `rpg_hud` / `basic_hud`.
3. Добавьте **Panel**, **Полоска HP**, **Золото**, кнопки.
4. Перетащите мышью; углы — размер (один Undo на жест).
5. Binding: `player.gold` / шаблон `{gold}`.
6. On Click → Открыть инвентарь / журнал.
7. Область: **Постоянный HUD**.
8. Сохранить → Preview / Test From Here.

## Village + HUD

1. Загрузить демо «Деревня» (Visual).
2. В Game UI применить `rpg_hud` (уже в demo JSON).
3. Preview: visual hotspots + persistent HUD вместе.

## Добавление изображения в Game UI (1.9.2)

1. Игровой UI → добавить **Изображение** (или портрет).
2. **Выбрать asset…** → общий Asset Picker (тот же, что у Visual Scene).
3. Поиск → `diary.svg` / `bag.svg` / свой asset.
4. Resize + **Snap** (сетка 0.05 по умолчанию).
5. On Click → Открыть панель → Журнал / Инвентарь.

## Snap

Чекбокс **Snap** и размер сетки рядом с подсказкой viewport.  
Один жест drag/resize = один шаг Undo.


## Действия по клику (несколько)

Цепочка по клику:

1. Действие 1 (реплика)
2. Действие 2 (выдать предмет)
3. Действие 3 (открыть сцену)

Кнопки: **+ Добавить действие**, ↑ / ↓, **Удалить**.

**Готовое действие** вставляет шаблон (предмет, золото, лечение, бой, квест) как обычные действия реестра — без macro-id в JSON проекта.


## Условия (когда доступно)

Условие отвечает: **можно ли выполнить клик?**

Действие отвечает: **что произойдёт?**

Формат в данных (как у выборов сцен):

```json
"showIf": { "all": [ { "hasItem": "village_key" } ] }
```

Все перечисленные условия должны выполняться (И).

Пример: сундук

1. Когда доступно → У игрока есть предмет → Ключ  
2. При нажатии → реплика → золото → забрать ключ

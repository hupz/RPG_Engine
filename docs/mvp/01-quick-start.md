# Quick Start

1. Open `editor.html` in a modern browser (or via local static server).
2. Click **Новый проект** (New Project).
3. Choose a **template**: Blank RPG / Text RPG / Visual Adventure / Village Demo.
4. Set project name + rule system → **Создать проект**.
5. Preview opens in editor-test isolation (`?editorTest=1`) — production Mill cache is not overwritten.
6. Edit scenes under **Сцены**; validate under project integrity / Validate; export JSON when ready.

You do **not** need to write JavaScript.

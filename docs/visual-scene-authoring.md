# Как создать интерактивную сцену без кода

Краткий гайд по **Visual Scene** в MythMill / RPG Engine.

## Три режима сцены

| Режим | Когда использовать |
|--------|-------------------|
| **TEXT** | Классическая IF: текст, выборы, диалоги. Поле `visual` отсутствует. |
| **Visual** | Карта/локация: фон + кликабельные области (hotspot), картинки, кнопки. |
| **Mixed** | Текст и выборы **плюс** визуальный слой (например описание + кликабельная карта). |

Обычные TEXT-сцены **не ломаются**: без `visual` движок работает как раньше.

---

## Быстрый сценарий: «Деревня»

1. Откройте **Editor** → вкладка **Сцены**.
2. Создайте или выберите сцену (например «Деревня»).
3. Прокрутите до блока **«Визуальный слой»**.
4. Режим: **Поверх сцены**.
5. **Фон** → кнопка выбора asset → `village.png` (или путь в `data.assets`).
6. **+ Hotspot** (или режим «нарисовать область» на viewport):
   - Таверна → **При нажатии** → **Открыть сцену** → Таверна  
   - Кузница → Открыть сцену → Кузница  
   - Лавка → Открыть сцену → Лавка  
   - Часовня → Открыть сцену → Часовня  
7. **+ Image** → дневник → **Открыть журнал** (панель интерфейса).
8. Перетащите и измените размер областей мышью на viewport.
9. **Сохранить** проект.
10. **Preview / Проверить** → клик по таверне → переход на сцену таверны.
11. **Undo** отменяет весь жест drag/resize целиком.

Код и JSON писать не нужно: Editor сохраняет `scene.visual.nodes` сам.

## Элементы

| Тип | Назначение |
|-----|------------|
| **Image** | Картинка на слое (из Asset Picker). |
| **Text** | Подпись на viewport. |
| **Button** | Кнопка HUD. |
| **Panel** | Декоративная панель. |
| **Hotspot** | Невидимая/полупрозрачная зона клика. |

## Действия при клике (человеческие названия)

Редактор показывает понятные подписи; в данных пишется id из **ACTION_REGISTRY**:

- Открыть сцену → `change_scene`
- Открыть инвентарь / журнал / меню… → `open_panel` + `panel`
- Выдать/забрать предмет, золото → `add_item` / …
- Обновить квест → `update_quest`
- Показать сообщение → `say`

## Viewport

- Координаты **0…1** относительно области фона.
- **Drag** и **resize** (углы).
- Опциональная **сетка** (snap).
- Режим **рисования hotspot**.

## Preview

Preview использует тот же **VisualRuntime**, что и игра.  
Runtime **не** зависит от Editor: в export достаточно game scripts + project data + assets.

## Undo

Один жест (перетаскивание или изменение размера) = **одна** запись истории.

## Asset Picker

Список строится из `project.assets` и уже использованных путей.  
Есть поиск и превью. Полный файловый менеджер диска не требуется.

## Демо: интерактивная деревня (без кода)

В Editor на панели **Визуальный слой** нажмите:

**📦 Загрузить демо «Деревня»**

Или откройте файл `data/demos/visual_village.json` как проект.

### Что внутри

| Место | Действие |
|-------|----------|
| Hotspot «Таверна» | Открыть сцену → Таверна |
| Hotspot «Лавка» | Открыть сцену → Лавка |
| Hotspot «Кузница» | Открыть сцену → Кузница |
| Hotspot «Часовня» | Открыть сцену → Часовня |
| Иконка дневника | Открыть журнал |
| Иконка сумки | Открыть инвентарь |

Здания открывают **обычные TEXT-сцены** с кнопкой «Выйти на площадь» обратно в деревню с visual-слоем.

### Preview

1. Выберите сцену `village`.
2. **Проверить сцену** / Test From Here.
3. Клики по областям вызывают `change_scene` / `open_panel` через registry — без JavaScript автора.

Кампания **Мельница** этим демо **не изменяется**.

## Создание интерактивной локации с нуля

Без JavaScript и без правки JSON вручную.

1. **Создать сцену** — вкладка Сцены → новая сцена (например «Площадь»).
2. **Фон** — Визуальный слой → Background → выбрать asset через Asset Picker (в демо: «Деревня (фон)» / `village.svg`).
3. **Картинка (опционально)** — «+ Image» → Asset Picker → иконка дневника или сумки.
4. **Область** — «+ Hotspot» → растянуть мышью над домом на фоне.
5. **On Click** — в Inspector: «Что происходит?» → **Открыть сцену** → выбрать цель (Таверна).
6. **Сохранить** проект.
7. **Preview** — «Проверить сцену» / Test From Here.

### Второй пример: открыть журнал

1. Добавить **Image** (дневник).
2. On Click → **Открыть панель** → Журнал.
3. Preview → клик по иконке открывает существующий Journal UI.

### Demo assets

В репозитории:

- `assets/images/village.svg` — схема площади (таверна / лавка / кузница / часовня);
- `assets/images/diary.svg` — иконка журнала;
- `assets/images/bag.svg` — иконка инвентаря.

После **Загрузить демо «Деревня»** они появляются в Asset Picker через `data.assets`.

Если файл отсутствует, Editor и Runtime не падают: пустой фон / прозрачная область, hotspot остаётся кликабельным.


## Действия по клику (несколько)

Цепочка по клику:

1. Действие 1 (реплика)
2. Действие 2 (выдать предмет)
3. Действие 3 (открыть сцену)

Кнопки: **+ Добавить действие**, ↑ / ↓, **Удалить**.

**Готовое действие** вставляет шаблон (предмет, золото, лечение, бой, квест) как обычные действия реестра — без macro-id в JSON проекта.


## Условия (когда доступно)

Условие отвечает: **можно ли выполнить клик?**

Действие отвечает: **что произойдёт?**

Формат в данных (как у выборов сцен):

```json
"showIf": { "all": [ { "hasItem": "village_key" } ] }
```

Все перечисленные условия должны выполняться (И).

Пример: сундук

1. Когда доступно → У игрока есть предмет → Ключ  
2. При нажатии → реплика → золото → забрать ключ
